# JOER — интерактивное интернет-радио

**joer.ru** — радио-портал, в котором визуальная атмосфера сайта подстраивается под музыку.

Пользователь выбирает не станцию, а настроение: **Lounge · Club · Romantic · Chill & Space · Jazz & Retro**.
Сайт запускает поток из выбранной группы и окрашивает всё вокруг в его настроение — палитра, фон, анимации, частицы.

## Стек

Статический сайт: HTML + CSS + JavaScript (браузерные ES-модули). Без сборки и рантайм-зависимостей.
Хостинг — GitHub Pages из ветки `main`, домен `joer.ru` (файл [`CNAME`](CNAME)).

## Локальный запуск

```bash
npm run serve       # python3 -m http.server 8080  →  http://localhost:8080
npm run validate    # проверка всех потоков из data/stations.json
```
