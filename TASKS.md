## T-09 — Настоящая реактивность и «дорогая» картинка

## T-10 — Стилизованный эквалайзер атмосферы (левый край, фон)

**Цель:** постоянный декоративный эквалайзер слева на фоне, в том же визуальном слое,
что и атмосфера — со своим рисунком под каждую из 5 сцен и живой привязкой к звучащему радио.

**Контекст для исполнителя:** данные спектра уже текут в движок —
`js/app.js` → `atmosphere.setLevels(levels)` → `this.rhythm.spectrum` (32 полосы, 0…1),
в сцены попадает через `params.spectrum` (`js/atmosphere.js:1005`). В реактивном режиме это
реальный спектр `AnalyserNode`, в процедурном — синтез от `rhythm.js`. Эту трубу использовать,
новых источников звука не заводить. Уже есть радиальный эквалайзер-кольцо
(`drawSpectrumRing`, используется в club) — задача добавит **второй, отдельный элемент**:
вертикальную композицию вдоль левого края.

Объём:

- **Расположение и слой**: вертикальная полоса высотой ~60–80% вьюпорта, прижатая к левому
  краю (с отступом по токенам), рисуется **внутри существующего canvas-слоя** `.atmosphere`
  (тот же z-index, `pointer-events: none`, под контентом) — НЕ отдельным DOM-элементом и НЕ
  поверх карточек/плеера. На узких экранах (< 720px) — либо скрыт, либо деградирует в узкую
  кромку ≤ 40px; карточки и текст не перекрывать (проверить 320px).
- **Реактивность**: полосы отвечают на `spectrum` в реальном времени; без CORS/без звука —
  тот же синтез-спектр, что у сцен (фолбэк уже есть, дублировать не нужно). Пауза → полосы
  плавно оседают в спокойное «дышащее» состояние, не замирают мёртвым столбиком.
- **Стиль по сценам** (каждой — свой рисунок, не «один и тот же бар-чарт с другим цветом»):
  - `waves` (lounge) — тонкие горизонтальные нити-струны, амплитуда от mid, блик как от лампочек бара;
  - `rings` (club) — жёсткие неоновые бары с резким пиком на кик, лёгкий вертикальный bloom;
  - `bokeh` (romantic) — мягкие «свечи»: столбцы света с большим размытием краёв, качание на mid, двойной отклик на «сердце»;
  - `stars` (space) — разреженные светящиеся точки-эквалайзер (точка = полоса), метеор-вспышка по высоких частотам;
  - `vinyl` (velvet) — ретро-столбики тёплого золота с VU-подобной инерцией (медленный подъём, мягкое падение), лёгкое зерно.
- **Палитра и режимы**: цвета только из CSS-переменных темы (как у сцен); уважать
  «спокойный режим» (амплитуда ×0.5, без вспышек) и `reduce-motion` (статичный кадр);
  quality `low` — упрощённый рисунок (без bloom/свечений), как у остальных сцен.
- **Производительность**: рисовать в общем цикле атмосферы, без нового rAF и без
  дополнительных offscreen-буферов на med/high; бюджет — не дороже одной сцены.

Критерии приёмки:

- [x] эквалайзер виден слева на фоне при каждой из 5 тем и меняет рисунок при смене темы (кроссфейд, как у сцен)
      — `js/equalizer.js`, рисуется в `composite()` тем же буфером/bloom; кадры 5 тем отрендерены
      реальным 2D-canvas (@napi-rs/canvas, вне репо) и проверены глазами на 1440 и 320px
- [x] при игре станции с CORS-потоком полосы следуют реальному спектру; без CORS — живой синтетический ритм
      (jsdom: громко/тихо/форма спектра доходят до полос; живой CORS-поток — после `audit:cors` на машине владельца)
- [x] пауза → плавное оседание; «спокойный режим» заметно смягчает; reduced-motion → статика

Попутно исправлены два бага T-09, найденные при визуальной проверке (покрыты регресс-тестами):

- **Засвет на med/high**: основной canvas не очищался между кадрами — полупрозрачные кадры и
  аддитивный bloom копились и за секунды выжигали фон в сплошную заливку. Теперь `clearRect` каждый кадр.
- **Синтез-спектр залипал в 1**: `base + prev·decay` сходилось к ~1.5 → все 32 полосы всегда на максимуме
  (radial-эквалайзер club без CORS был полным неподвижным кругом). Теперь огибающая пика `max(new, prev·decay)`.

## T-11 — Эквалайзер под текстом, сворачиваемый герой, адаптив под фолды

**Цель:** эквалайзер больше не зажат в «узкой полке» слева от текста — он свободно заходит
под текст и карточки; герой сворачивается к верху («наслаждаться атмосферой»); вёрстка
доведена на телефонах и фолд-экранах.

Объём:

- **Эквалайзер под текстом** (`js/equalizer.js`): полоса у левого края расширена до 20%
  вьюпорта (96–320px) и не ограничивается свободным полем слева от колонки контента;
  под текстом она приглушается (`fade` 0.6), чтобы не спорить с читаемостью.
  Компакт-кромка (< 560px) — до 9% ширины (≤ 40px), чуть заходит под контент.
  Брейкпоинт компакт-режима поднят 720 → 560px, чтобы раскрытый фолд (585–673px)
  получал полноценную полосу.
- **Сворачивание героя** (`js/ui/hero.js`): кнопка «Свернуть/Развернуть» сворачивает
  тело героя к верху (grid 1fr→0fr, `inert` на тело, `aria-expanded`), состояние
  переживает перезагрузку (`joer:heroCollapsed`). «Продолжить» разворачивает свёрнутый
  герой (кнопка живёт в герое), а клик по «Продолжить» снова сворачивает — музыка
  пошла, остаётся атмосфера.
- **Адаптив**: заголовок героя `clamp(28px … 56px)` + `text-wrap: balance/pretty`
  (тире «Выбери настроение —» больше не сиротит на новой строке); компактный герой на
  низких вьюпортах (`max-height: 620px` — пейзаж телефона/фолда); сетка станций 2 колонки
  с 560px (раскрытый фолд); кнопки героя на всю ширину ≤ 480px; ярлык и кнопка сворачивания
  в один ряд; `flex: 1 1 0` у меты плеера (длинный текст не выталкивал кнопки на второй ряд);
  `scroll-margin-top` у якоря `#stations` под sticky-хедером.

Критерии приёмки:

- [x] эквалайзер заходит под текст: 1440px — полоса 288px (колонка текста начинается ~162px),
      1280px — 256px; под текстом fade < 1; jsdom-проверки раскладки в `npm test`
- [x] на 320px контент читаем, кромка ≤ 40px почти целиком в боковом поле; `overflowX = 0`
      на 320/390/585/673/832/1280/1440 (headless Chromium, реальные скриншоты просмотрены)
- [x] герой сворачивается/разворачивается кнопкой, состояние переживает перезагрузку,
      «Продолжить» разворачивает свёрнутый герой, клик — сворачивает снова (jsdom, +19 проверок)
- [x] `npm test` — 206 проверок (+19 по T-11), все зелёные

## T-12 — Режим «Только атмосфера» (киноэкран для большого экрана)

**Цель:** режим, в котором на экране кроме живой атмосферы ничего нет — вывести сайт
на большой экран и просто смотреть, как миры перетекают друг в друга.

Объём:

- **Вход** (`js/ui/ambient.js`, кнопка `#ambient-btn` рядом со «Свернуть»): интерфейс
  (.page: хедер, герой, каталог, плеер) плавно гаснет и становится `inert`, сцена
  переходит в полную прозрачность; по возможности запрашивается Fullscreen API
  (панель браузера тоже уходит; без жеста/разрешения режим работает и так).
- **На экране только атмосфера**: фоновый градиент + canvas-сцена + зерно + виньетка
  и эквалайзер (они и есть слой атмосферы). Музыка продолжает играть.
- **Сама смена миров**: каждые ~90 с тема перетекает по кругу lounge → club → romantic →
  space → velvet (штатный кроссфейд сцен 800 мс); reduced-motion — один спокойный мир.
  Выбор пользователя не портится: на выходе тема восстанавливается (`themes.resolve()`),
  в хранилище ничего не пишется.
- **Выход**: клик/тап в любом месте (после grace-периода) или Esc; подсказка
  «Атмосфера · клик или Esc — выйти» всплывает на ~5 с при входе и тихо уходит.
- **Большой экран по ссылке**: `joer.ru/#atmosphere` открывается сразу в режиме
  (удобно для телевизора/киоска); выход очищает хэш.

Критерии приёмки:

- [x] на экране ничего кроме атмосферы: интерфейс скрыт и `inert`, сцена в полную силу;
      скриншоты 1440/390 (lounge, club) просмотрены — только сцена и краткая подсказка
- [x] миры перетекают сами; тема пользователя восстанавливается на выходе; reduced-motion — без смены
- [x] выход кликом или Esc; `#atmosphere` запускает режим сразу (jsdom)
- [x] `npm test` — 223 проверки (+17 по T-12), все зелёные
