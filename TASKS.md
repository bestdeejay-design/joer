## T-03 — Плеер

**Цель:** надёжное воспроизведение с человеческими состояниями.

Объём:

- `js/player.js`: обёртка `<audio>`, состояния `idle/loading/playing/paused/error`, громкость/mute (persist).
- Реконнект: 3 попытки с backoff (1s / 2s / 4s) при error/stalled; затем предложение следующей станции группы.
- Media Session API (title/artist, play/pause).
- Футер-плеер: текущая станция, play/pause, громкость, mute; статусы «Буферизация…», ошибка с кнопкой «Повторить».
- Клик по карточке станции запускает её и обновляет плеер.

Критерии приёмки:

- [~] 3 станции из разных групп играют после клика: проверено в jsdom — клик → `audio.src`
      → состояние `playing` для lounge/club/romantic/jazz. Живые Chrome/Safari/Firefox —
      на этапе T-08 (в среде исполнителя нет браузера).
- [x] подмена URL на нерабочий → видимая ошибка → авто-переход на следующую станцию группы
      (1 + 3 попытки с backoff, затем событие `exhausted` с предложенной станцией)
- [x] громкость/mute переживают перезагрузку страницы (`joer:volume`, `joer:muted`)
- [~] лок-скрин (iOS/Android): Media Session API подключён (title/artist/album, play/pause/stop,
      next/prev), проверка на устройстве — на T-08
- [x] повторный клик по играющей станции не вызывает петлю перезапусков (idempotent play/pause)

## T-06 — Атмосферный движок

**Цель:** фон-сцена, живущая вместе с музыкой.

Объём:

- `js/atmosphere.js`: canvas-слой, сцены по темам (волны / кольца / боке / звёзды / винил), параметры от `energy` и состояния плеера.
- Смена темы → кроссфейд сцен ~800 мс.
- Перф: пауза при `document.hidden`, DPR ≤ 2, кап fps (60/30), плавное «засыпание» при paused.
- Опциональная реактивность Web Audio — только с безопасным фолбэком; звук не ломается никогда (см. ARCHITECTURE.md).
- reduced-motion → статичная композиция.

Критерии приёмки:

- [x] каждая тема имеет отличимую сцену (волны / кольца / боке / звёзды / винил);
      energy станции и пользовательская интенсивность меняют скорость сцены
- [x] при скрытии вкладки анимация останавливается (`visibilitychange` → cancelAnimationFrame;
      замер CPU в профайлере — на T-08)
- [x] пауза → сцена плавно замирает, play → оживает (лерп «живости», без скачков)
- [~] 30-минутная сессия: длинный прогон в реальном браузере — на T-08; по коду массивы
      частиц ограничены (кольца отфильтровываются по радиусу, метеор один, спрайты кэшированы)
- [x] с реактивностью и без неё воспроизведение не отличается: Web Audio подключается только
      для станций с `cors: true` (в каталоге таких нет), при любой ошибке/тишине анализатора —
      фолбэк и пересоздание `<audio>` без графа
