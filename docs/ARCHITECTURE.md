# Архитектура — JOER

## Хостинг и ограничения

- GitHub Pages из `main` (root), домен `joer.ru` (файл `CNAME`), HTTPS обязателен.
- **Следствие: все аудиопотоки должны быть https** — иначе браузер заблокирует mixed content.
- Сайт статический: никакого бэкенда. Всё состояние — локально (localStorage).

## Стек и принципы

- HTML + CSS + браузерные ES-модули (`<script type="module">`). Без сборки, без npm-зависимостей в рантайме.
- Данные каталога — статический JSON, загружается через `fetch`.
- Прогрессивное улучшение: базовый сценарий работает без Web Audio, без PWA, без сервис-воркера.

## Структура (целевая)

```
index.html
css/
  tokens.css        дизайн-токены (цвета, шрифты, отступы, радиусы, тайминги)
  base.css          reset + базовая тёмная тема
  layout.css        каркас страницы (header / каталог / футер-плеер)
  components/       карточка станции, табы групп, плеер-бар, поиск...
  themes/           lounge.css · club.css · romantic.css · space.css · velvet.css
js/
  app.js            точка входа, связывает модули и UI
  catalog.js        загрузка/валидация data/stations.json, группировка, поиск
  player.js         аудио-движок (<audio>), состояния, реконнект, Media Session
  themes.js         переключение тем, авто/ручной режим, персистентность
  atmosphere.js     canvas-фон, сцены тем, интенсивность
  storage.js        обёртка localStorage (версионированные ключи)
  ui/               рендер каталога, плеер-бара, селекторов (по мере роста)
data/
  stations.json     каталог станций
scripts/
  validate-stations.mjs   проверка потоков (node, без зависимостей)
```

## Модель данных — `data/stations.json`

```jsonc
{
  "version": 1,
  "updatedAt": "2026-10-11",
  "groups": [
    {
      "id": "lounge",
      "title": "Lounge",
      "subtitle": "Лаунж и чиллаут",
      "description": "…",
      "theme": "lounge",                 // тема по умолчанию для группы
      "defaultStationId": "somafm-groovesalad"
    }
  ],
  "stations": [
    {
      "id": "somafm-groovesalad",        // уникальный, kebab-case
      "groupId": "lounge",               // ссылка на groups[].id
      "name": "Groove Salad",
      "provider": "SomaFM",
      "url": "https://ice2.somafm.com/groovesalad-128-aac",
      "codec": "aac",                    // aac | mp3 | ogg | flac
      "bitrate": 128,                    // kbps, справочно
      "genres": ["chillout", "downtempo"],
      "mood": "расслабленный",
      "energy": 2,                       // 1..5 — драйв; управляет интенсивностью атмосферы
      "description": "…",
      "homepage": "https://somafm.com/groovesalad/",
      "cors": true                       // опционально: поток отдаёт Access-Control-Allow-Origin
    }
  ]
}
```

Правила каталога:

- Только прямые stream-URL (для SomaFM: `https://ice2.somafm.com/<id>-128-aac`); **никаких .pls/.m3u** — браузер их не играет.
- Новые станции добавляются только после `npm run validate`.
- `energy` честно отражает жанр: 1 — эмбиент/дрон, 3 — хаус/поп, 5 — ударные клубные жанры.

## Плеер

- Один `<audio>` элемент; управление через модуль `player.js`.
- Состояния: `idle → loading → playing ⇄ paused → error`; UI отражает каждое.
- **Реконнект**: при `error` или затянувшемся `waiting` (>12 c) — до 3 переподключений с backoff (1s → 2s → 4s); после — предложение следующей станции группы.
- Слушать события `stalled`, `suspend`, `waiting`; по таймауту — reconnect.
- **Media Session API**: title = станция, artist = группа; кнопки play/pause/stop.
- Громкость: 0..1, сохраняется; mute — отдельный флаг.
- Автозапуск запрещён: старт только по жесту; «продолжить последнюю» — кнопкой.

## Темы

- Тема = атрибут `data-theme` на `<html>` + набор CSS-переменных в `css/themes/<id>.css`.
- 5 тем: `lounge`, `club`, `romantic`, `space`, `velvet` (см. DESIGN.md).
- Режимы: **авто** (тема = текущая группа; по умолчанию) и **ручной** (выбор пользователя отключает авто).
- Переход между темами — плавный (транзишен цветов ~600–900 мс + кроссфейд фонового слоя).
- Персистентность: выбранная тема и режим в localStorage.

## Атмосфера (canvas)

- Слой `<canvas>` на заднем плане; сцена выбирается по теме, параметры — по станции.
- База — **процедурная анимация** (волны, кольца, боке, звёзды, винил — по теме), всегда работает.
- **Интенсивность** = f(energy) и состояние плеера: пауза → движение замирает.
- **Ритмический слой** (`js/rhythm.js`): единый источник «пульса» для сцен.
  Реактивный режим — onset-детектор по басу (удары попадают в музыку);
  процедурный — музыкальный паттерн (кик/снейр/хэт) с темпом от `energy` станции.
  Роли полос спектра: **bass** → масштаб/пинок, **mid** → скорость дрейфа, **high** → мерцание/искры.
- **Bloom-пасс**: сцена рисуется в offscreen, даунскейл + аддитивное наложение обратно
  (cheap glow без `shadowBlur`). Плотность — по режиму качества.
- **Параллакс** от курсора и скролла (~14 px, глубина по слоям сцены) + «протирка»
  светом при кроссфейде сцен (~800 мс с easing).
- **Эквалайзер у левого края** (`js/equalizer.js`, T-10): вертикальная полоса 60–80% высоты,
  рисуется внутри того же canvas и того же кадра (общий bloom и кроссфейд, без своего rAF/буферов).
  Данные — `rhythm.spectrum` (реальный или синтез), сглаживание `EqualizerBands`: на паузе
  полосы оседают в тихое «дыхание». Свой рисунок на сцену: струны (waves), неоновые бары с пиком
  на кик (rings), свечи (bokeh), точечная матрица с метеором (stars), сегментный VU с инерцией (vinyl).
  < 720px — кромка ≤ 40px в боковом поле контента; calm — амплитуда ×0.5 без вспышек; low — без свечений.
- **Режимы**: качество `low | med | high` (bloom и плотность эффектов) и «спокойный
  режим» (calm) — мягкое движение без вспышек, для тех, кому много. Рядом с
  системным `prefers-reduced-motion` (тот даёт статичный кадр). Выбор — в меню темы, persist.
- **Опциональная аудио-реактивность**: `Web Audio API` + `AnalyserNode` возможен только если поток отдаёт CORS-заголовки (большинство радиостанций — нет). Стратегия:
  1. Поддержка подтверждается до подключения графа: флаг `cors: true` в каталоге (после `npm run audit:cors`) или проба `probeStreamCors()` — обычный GET в режиме cors с обрывом тела; результат кэшируется в `joer:cors-cache`. Явный `cors: false` — никогда.
  2. Если анализатор не даёт данных или звук деградирует — **немедленно** вернуться к процедурной анимации, при необходимости пересоздав `<audio>` без Web Audio-графа.
  3. Сцена строится так, чтобы выглядеть полноценно и без реактивности; radial-эквалайзер и «пинки» работают и на синтезированном спектре.
- Производительность: rAF с капом ~60 fps (30 fps на слабых устройствах / battery saver), пауза при `document.hidden`, DPR ≤ 2, уважение `prefers-reduced-motion` (статичная композиция).

## Хранилище (localStorage, префикс `joer:`)

| Ключ | Значение |
| --- | --- |
| `joer:favorites` | массив stationId |
| `joer:lastStation` | stationId последнего воспроизведения |
| `joer:volume` | 0..1 |
| `joer:theme` | id темы или `auto` |
| `joer:intensity` | 0..1 — интенсивность атмосферы |
| `joer:quality` | `low` \| `med` \| `high` — качество сцены |
| `joer:calm` | boolean — «спокойный режим» |
| `joer:cors-cache` | кэш проб CORS по URL потоков |

## Контроль изменений

- `npm run validate` — обязателен после правок `data/stations.json`: проверяет https, код ответа, content-type, целостность связей групп.
- `npm run audit:cors` — проверяет, какие потоки отдают `Access-Control-Allow-Origin`
  (нужно для аудио-реактивности); `npm run audit:cors -- --write` проставляет флаг `cors` в каталог.
- Деплой: пуш в `main` → GitHub Pages пересобирает сайт (~1 мин). Проверка: `curl -sI https://joer.ru`.

## Поддержка браузеров

- Chrome / Edge / Safari / Firefox — последние 2 версии; iOS Safari 16+; Android Chrome.
- AAC-потоки поддерживаются повсеместно; при расширении каталога следить за кодеками (mp3 — самый безопасный фолбэк).

## Известные ограничения

- Веб-плеер не показывает метаданные ICY («сейчас играет») без прокси — не показываем; ограничиваемся описанием станции.
- Мобильные браузеры могут останавливать аудио при сворачивании вкладки — это нормально, UI отражает состояние.
- `.pls` / `.m3u` не поддерживаются нативно — только прямые URL.
