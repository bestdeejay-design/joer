# Дизайн — JOER: темы и атмосфера

## Принципы

- **Тёмная база всегда.** Радио чаще слушают вечером и ночью; светлые темы — не в MVP.
- **Цвет = настроение.** Каждая группа станций имеет свой «мир»; переход между мирами — событие, а не переключатель.
- **Тишина в интерфейсе.** Минимум текста, никаких баннеров; контент — станции и атмосфера.
- **Сцена, а не фон.** Фон — лёгкая живая сцена (волны/частицы), которая не конкурирует с UI за внимание.
- **Доступность**: контраст текста ≥ 4.5:1, focus-visible, reduced-motion.

## Атмосферный движок

Слои (снизу вверх):

1. **Градиент-база** — CSS, статичный, от темы.
2. **Canvas-сцена** — JS, живая, от темы + энергия станции.
3. **Контент UI** — читаемый, не перекрывается сценой.

Параметры сцены от `energy` (1..5): амплитуда, скорость, плотность, яркость.
Состояние плеера: playing → полная живость; loading → лёгкое ожидание (замедление); paused → почти стоп («дыхание»); error → стабилизация, без тревоги.

Переходы смены темы: кроссфейд 800 мс (fadeout старой сцены → fadein новой), палитра — CSS-transition.
`prefers-reduced-motion`: сцена превращается в статичную градиентную композицию с одним минимальным «дыханием» (или без него).

Никаких стробоскопов и резких вспышек ни в одной конфигурации — это сайт-настроение, а не клубный свет. Клубная тема может пульсировать ритмично, но мягко.

## Типографика и язык

- Системный шрифт-стек (SF / Segoe / Roboto) — без внешних загрузок; заголовки — тот же стек, вес 600–700, трекинг плотнее.
- Интерфейс — русский; названия станций/жанров — как у провайдера (латиница).
- Статусные числа/тайминги — моноширинно (там, где мигают).

## Ключевые компоненты

- **Табы групп** — 5 пилюль; активная — подложка из акцента темы; горизонтальный скролл на мобиле.
- **Карточка станции** — название, провайдер, 2–3 жанра, energy-точки, звёздочка избранного; клик = играть; активная карточка подсвечена «дышащей» рамкой.
- **Футер-плеер (sticky)** — станция + группа, play/pause, громкость, mute; на мобиле — safe-area снизу.
- **Селектор темы** — компактный (Авто + 5 тем); при ручном выборе «авто»-подсветка снимается.
- **Поиск** — по названию/жанру/провайдеру; мгновенный фильтр, пустое состояние с подсказкой.

## Мобильный опыт

- One-hand: все критичные контролы — в нижней трети экрана; тач-таргеты ≥ 44px.
- Сетка станций: 1 колонка ≤ 480px, 2 — до 900px, 3–4 — шире.
- Плеер не «отбирает» экран: компактный бар, детали — по раскрытию.
