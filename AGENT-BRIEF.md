## Жёсткие правила

- **Без сборки и зависимостей**: браузерные ES-модули; никакого npm-рантайма. Node нужен только для `npm run validate`.
- **Только https-потоки** (страница на HTTPS → mixed content блокируется). Новые станции добавляй только после `npm run validate`.
- **Не трогать**: `CNAME`, `.nojekyll`, настройки домена и Pages.
- **Атмосферный движок не должен зависеть от Web Audio**: реактивность — опциональный слой с тихим фолбэком на процедурную анимацию; звук никогда не должен ломаться (см. ARCHITECTURE.md, «Атмосфера»).
- **Автоплей запрещён браузерами**: воспроизведение всегда стартует по явному жесту; «продолжить последнюю станцию» — тоже в один клик.
- Уважай `prefers-reduced-motion`; тач-таргеты ≥ 44px; никаких внешних скриптов, шрифтов и CDN.
