# AGENTS.md — правила для ИИ-агентов, работающих с этим репозиторием

Это репозиторий проекта **JOER** (joer.ru) — интерактивное интернет-радио.

**Прежде чем что-либо делать:**

1. Прочитай [`AGENT-BRIEF.md`](AGENT-BRIEF.md) — стартовый бриф.
2. Прочитай [`TASKS.md`](TASKS.md) — план работ; выполняй задачи по порядку (T-01 → T-08).
3. Контекст: [`docs/CONCEPT.md`](docs/CONCEPT.md), [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), [`docs/DESIGN.md`](docs/DESIGN.md).

**Короткие правила:**

- Статический сайт без сборки: браузерные ES-модули, никаких npm-зависимостей в рантайме.
- Только https-потоки; после правок каталога — `npm run validate`.
- Не трогать `CNAME`, `.nojekyll` и настройки GitHub Pages.
- Одна задача TASKS.md = один коммит; отмечай выполнение и записывай доказательства проверки в «Журнал выполнения».
